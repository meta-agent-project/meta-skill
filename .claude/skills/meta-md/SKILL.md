# meta-md

md는 짧아야 읽힌다.
길게 쓰면 아무도 읽지 않는다.

## 분량

- 최대한 요약한다. 꼭 필요한 것만 남긴다
- 한 문장에 한 가지만 쓴다
- 배경 설명, 꾸밈말, 같은 말 되풀이는 뺀다
- 다른 파일에 있는 내용은 다시 쓰지 않고 경로만 적는다
- 다 쓴 뒤 한 번 더 줄인다. 빼도 뜻이 통하면 뺀다

## 기호

| 쓴다 | 안 쓴다 |
|---|---|
| # 제목 | ** 굵은 글씨 |
| - 목록 | 1. 2. 숫자 목록 |
| 표 | 벡틱 1개 |
| ``` 코드 블록 | [글자](주소) 링크 |
| 이미지 넣는 기호 | 이모지 |

주소는 기호 없이 그대로 적는다.
https://github.com/meta-agent-project/codeproject-agent

## 줄바꿈

- 문장마다 줄을 바꾼다
- 빈 줄은 내용이 바뀔 때만 넣는다
- 제목 앞뒤에는 빈 줄을 넣는다

## 한글

humanize-korean 규칙 중 쓸 때 지킬 것만 모았다.

- 문체는 "~한다", "~다"로 맞춘다
- 번역투를 쓰지 않는다. "~에 대해", "~에 있어", "가지고 있다", "~되어진다", "~에 의해"
- AI 말버릇을 쓰지 않는다. "결론적으로", "요약하면", "다음과 같다", "매우 중요하다", "핵심은 ~다", "~하는 이유다", "~다는 것이다"
- "A가 아니라 B" 같은 대구는 문서에 한 번만 쓴다
- -고, -며, -지만 뒤에 쉼표를 찍지 않는다
- 제목에 "X: Y" 콜론을 쓰지 않는다
- 따옴표 강조와 대시(—) 덧붙이기를 쓰지 않는다
- 영어는 처음 한 번만 괄호로 함께 쓴다
- "~하고 있다"는 "~한다"로 줄인다
- 같은 어미가 네 문장 넘게 이어지면 바꾼다
- 고유명사, 숫자, 명령어, 파일 이름은 그대로 둔다

## 순서

- 쓰기 전에 이 문서가 전할 것을 세 줄 안으로 정한다
- 쓴다
- 점검하고 고친다

## 점검

- 안 쓰는 기호가 남았는가
- 빼도 되는 문장이 남았는가
- 한글 규칙에 걸리는 말이 있는가

이미 있는 md를 고쳐 달라고 하면 같은 점검으로 고친다.
내용, 숫자, 이름은 바꾸지 않는다.
