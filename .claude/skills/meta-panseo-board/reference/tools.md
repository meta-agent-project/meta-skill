# 판서보드 엔진 내부 구조

엔진은 template/board_template.html의 `<script id="engine">` 한 곳에 있다.
참고용 문서이며 엔진은 고치지 않는다.

## 화면 층

| 층 | 요소 | 하는 일 |
|---|---|---|
| 1 | `#paper` | 배경색과 모눈 |
| 2 | `#slides` | 슬라이드 내용. 포인터를 받지 않는다 |
| 3 | `#pad` | 판서 캔버스. 모든 입력을 받는다 |
| 4 | `#ui` | 선택 테두리와 손잡이 |
| 5 | `#editor` | 글 입력 상자 |
| 6 | 레일, 오른쪽 위 캡슐, 펼침 메뉴 | 도구 |

## 데이터 모델

페이지마다 객체 배열 하나(`layers[i]`)를 둔다. 픽셀이 아니라 객체로 저장하므로 겹친 것도 따로 잡히고, 창 크기가 바뀌어도 다시 선명하게 그린다.

```text
획      { t:'stroke', color, size, pts:[{x,y,p}] }          // p = 필압
도형    { t:'rect'|'ellipse'|'tri'|'arrow'|'diagram', x,y,w,h, rot, color, size }
세모    p:[[u,v]×3]   // 상자 안 비율 좌표
다이어그램 title, body, fs
글      { t:'text', x,y,w,h, rot, color, fs, text }
```

- 화살표는 (x,y)가 시작점, (x+w, y+h)가 끝점이다. w, h는 음수일 수 있다.
- 회전은 상자 중심 기준 라디안이다. `toLocal`, `toWorld`가 좌표를 바꾼다.

## 자동 도형 맞춤

1. 펜이 5px 넘게 움직일 때마다 0.55초 타이머를 다시 건다.
2. 타이머가 끝나면 `recognize(pts)`가 판정한다.
   - 시작점과 끝점이 가까워야 한다(닫힌 모양).
   - 가장 먼 점에서 고리를 둘로 나눠 Douglas–Peucker로 꼭짓점을 줄이고, 거의 직선인 꼭짓점을 지운다.
   - 꼭짓점 3개와 면적비 0.28~0.72 → 세모(꼭짓점 그대로)
   - 꼭짓점 4개와 면적비 0.74 초과 → 네모
   - 꼭짓점 4개 이상과 면적비 0.64~0.9 → 동그라미
3. 맞으면 획을 도형으로 바꾸고 "○○로 맞춤 · 원래대로" 칩을 3.5초 보여 준다.

## 선택, 회전, 크기

- `pickItem`: 위에서부터 찾는다. 획은 선까지 거리, 글·다이어그램은 상자 안, 나머지 도형은 테두리까지 거리로 판정한다.
- 도형·글 하나를 고르면 오른쪽 위에 회전 손잡이, 오른쪽 아래에 크기 손잡이를 그린다. 화살표는 회전만 된다.
- 회전은 0°, 90°, 180°, 270° 근처 4° 안에서 붙는다.
- 여러 개를 묶으면 이동, 복제, 삭제, 색 바꾸기만 된다.

## 지우개

- 그리는 동안은 `destination-out`으로 지워 보인다.
- 손을 떼면 `applyErase`가 획의 경로 근처 점을 잘라 조각으로 나눈다. 옮겨도 돌아오지 않는다.
- 도형은 테두리에, 글은 상자 안에 닿으면 통째로 지운다. 다이어그램 안쪽에 쓴 판서를 지우다 상자가 지워지지 않게 하려는 것이다.

## 되돌리기

- 바뀌기 직전 배열을 JSON 문자열로 쌓는다(최대 80개).
- 선택해서 옮길 때는 실제로 움직인 순간에만 쌓는다. 누르기만 해서는 쌓이지 않는다.
- 페이지를 바꾸면 기록을 비운다.

## 배경

- `<body data-bg>`가 `white` 또는 `chalk`. CSS 변수가 글자색, 강조색, 다이어그램 제목 칸 색을 함께 바꾼다.
- 팔레트는 같은 자리끼리 짝이다. 화이트의 검정 ↔ 칠판의 흰색처럼 모든 페이지와 되돌리기 기록의 색을 바꾼다.

## 모션

reference/motion.md 참고. `window.MOTION`에 `interpolate`, `spring`, `Easing`, `on`, `replay`가 있다.

## 태블릿

- 오른쪽 위 ⛶ 버튼이 전체화면을 켜고 끈다. 갤럭시탭은 F11이 안 되고 탭할 때만 전체화면이 허용된다.
- 캔버스 pointerdown에서 기본 동작을 막아, 글 상자를 놓자마자 입력이 들어가게 한다.
