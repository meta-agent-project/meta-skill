# 판서보드 엔진 내부 구조

엔진은 template/board_template.html의 `<script>` 한 곳에 있다.
참고용 문서이며 엔진은 고치지 않는다.

## 데이터 모델

판서는 픽셀이 아니라 획 객체 배열로 저장한다.

```text
stroke = { color, size, erase:false, pts:[{x, y, p}, ...] }   // p = 필압
```

- pointerdown부터 pointerup까지가 한 획, 객체 하나다.
- 화면은 `render()`가 배열을 다시 그려서 보여준다.
- 슬라이드마다 `slideStrokes[i]`, 판서모드는 `boardStrokes`로 배열이 따로 있다. 오가도 판서가 남는다.
- 창 크기가 바뀌면 `fit(true)`가 다시 그린다. 벡터라서 선명하다.

## 선택과 이동

- `pickStroke(p)`: 누른 곳에서 거리 12+굵기 안의 가장 위 획 하나를 찾는다. 겹친 다른 획은 잡히지 않는다.
- `liftStrokes(idxs)`: 고른 획을 배열에서 빼서 띄운다.
- `commitFloat()`: 옮긴 거리를 좌표에 더해 배열에 다시 넣는다.
- ✋이동은 손을 떼면 바로 내려놓는다. ✂선택은 바깥을 누르거나 Esc를 누를 때 내려놓는다.

## 지우개

- 그리는 동안은 `destination-out`으로 지워 보여준다.
- 손을 떼면 `applyErase(path)`가 경로 근처 점을 잘라내 획을 여러 조각으로 나눈다.
- 지운 부분은 데이터에서 사라지므로 옮겨도 돌아오지 않는다.

## 되돌리기

- `snapshot()`: 획 추가, 이동, 지우기, 전체지움 직전에 배열의 얕은 복사를 쌓는다.
- `doUndo()`: 쌓은 배열로 바꾸고 다시 그린다.
- 슬라이드나 판서모드를 바꾸면 되돌리기 기록을 비운다.

## 배경

- `setBg(name)`가 `<body data-bg>`를 navy, chalk, white, black 중 하나로 바꾼다. CSS가 화면과 판서모드 칠판 색을 함께 바꾼다.
- white로 들어가거나 나올 때 펜 팔레트를 DARK와 LIGHT 사이에서 바꾼다. 같은 자리의 색끼리 대응한다.
- 모든 레이어와 되돌리기 기록의 획 색도 같은 규칙으로 바꾼다.
- 선택한 배경은 localStorage의 `panseo-bg`에 저장한다. 저장이 막힌 환경에서는 저장만 건너뛴다.

## 단축키

`w` 배경 · `b` 판서모드 · `g` 모눈 · `e` 지우개 · `c` 전체지움 · `Esc` 조각 고정 · `Ctrl/Cmd+Z` 되돌리기 · `←→`, `PageUp/Down` 슬라이드

## 태블릿

좌상단 `⛶` 버튼이 `requestFullscreen()`을 켜고 끈다. webkit 접두사도 지원한다.
갤럭시탭은 키보드를 꽂아도 F11이 안 되고, 화면을 탭했을 때만 전체화면이 허용된다.
펜 판서 중 오작동을 막으려고 화면 전체가 아니라 작은 코너 버튼에만 건다.
컷이 하나뿐이면 좌우 화살표와 쪽 표시를 숨긴다.
