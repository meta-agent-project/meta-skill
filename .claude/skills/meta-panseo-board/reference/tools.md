# 판서보드 엔진 내부 구조

엔진은 template/board_template.html의 `<script id="engine">` 한 곳에 있다.
참고용 문서이며 엔진은 고치지 않는다.

## 화면 층

| 층 | 요소 | 하는 일 |
|---|---|---|
| 1 | `#paper` | 배경색과 모눈 |
| 2 | `#slides` | 슬라이드 내용. 포인터를 받지 않는다 |
| 2.5 | `#imgs` | 붙여넣은 이미지. 판서보다 아래라 판서가 늘 위에 보이고, 지우개가 이미지를 건드리지 않는다 |
| 3 | `#pad` | 판서 캔버스. 모든 입력을 받는다 |
| 4 | `#texts` | 글 상자(DOM). 편집할 때만 입력을 받는다 |
| 5 | `#ui`, `#ring` | 선택 테두리와 손잡이, 지우개 원 |
| 6 | `#editor` | 다이어그램 박스 글 입력 |
| 7 | 레일, 오른쪽 위 캡슐, 펼침 메뉴, 서식 바, 크기 표시 | 도구 |

## 데이터 모델

페이지마다 객체 배열 하나(`layers[i]`)를 둔다. 픽셀이 아니라 객체로 저장하므로 겹친 것도 따로 잡히고, 창 크기가 바뀌어도 다시 선명하게 그린다.

```text
획      { t:'stroke', color, size, pts:[{x,y,p}] }          // p = 필압
도형    { t:'rect'|'ellipse'|'tri'|'arrow'|'diagram', x,y,w,h, rot, color, size }
세모    p:[[u,v]×3]   // 상자 안 비율 좌표
다이어그램 title, body, fs
글      { t:'text', x,y,w,h, rot, color, fs, html }   // h는 화면에서 잰 높이
이미지  { t:'image', img, x,y,w,h, ar, rot }            // img = IMGS의 키, ar = h/w
```

- 화살표는 (x,y)가 시작점, (x+w, y+h)가 끝점이다. w, h는 음수일 수 있다.
- 회전은 상자 중심 기준 라디안이다. `toLocal`, `toWorld`가 좌표를 바꾼다.

## 글 상자

- 글은 캔버스가 아니라 `#texts` 안의 div로 그린다. 그래서 글자 일부에만 굵게, 밑줄, 색, 크기를 줄 수 있다.
- 편집은 그 div를 `contenteditable`로 바꿔서 한다. 서식은 `execCommand`(bold, italic, underline, strikeThrough, foreColor, hiliteColor, removeFormat)로 넣는다.
- 범위 크기 조절은 고른 부분을 `font-size: 1.15em` 또는 `0.87em` span으로 감싼다. em이라 상자 전체 글자 크기를 바꾸면 함께 커진다.
- 붙여넣기는 글자만 받는다.
- 편집을 닫으면 내용을 `html`에 저장하고, 비었으면 상자를 지운다. 바깥 탭이나 Esc로 닫으면 선택 도구로 바꾸고 그 상자를 선택한다.
- 다이어그램 박스는 제목과 본문만 있는 일반 글이라 지금처럼 textarea로 편집한다.

## 이미지

- 원본 dataURL은 `IMGS[id]`에 한 번만 두고, 객체에는 `img: id`만 넣는다. 되돌리기 기록(JSON)에 이미지가 복사되지 않는다. 복제해도 같은 id를 쓴다.
- 들어오는 길은 세 가지다. 문서의 `paste` 이벤트(클립보드의 image/* 파일), 창에 끌어다 놓기, 더보기 > 이미지 넣기(파일 선택). 모두 `addImageBlob(blob, 위치)`로 모인다.
- 글 편집 중이거나 입력 칸에 포커스가 있으면 붙여넣기를 가로채지 않는다(글자 붙여넣기 유지).
- 긴 변이 2560px을 넘으면 줄여서 보관한다. 처음 크기는 원본 ÷ devicePixelRatio이고 화면의 70%를 넘지 않는다. 마지막 펜 위치를 중심으로 놓는다.
- `pickItem`은 이미지가 아닌 것을 먼저 찾고 이미지는 마지막에 찾는다. 이미지 위에 쓴 판서를 누르면 판서가 잡힌다.
- 크기 손잡이는 끈 위치를 상자 대각선에 투영해 비율(`ar`)을 유지한다.
- `applyErase`는 이미지를 그대로 둔다. 지우려면 선택 후 Del.

## 크기 조절 [ ]

`sizeStep(dir)` 한 곳에서 상황을 보고 고른다.

1. 글 편집 중이고 범위가 있으면 그 범위
2. 선택한 것 중 글·다이어그램이 있으면 그 글자 크기(`fs`)
3. 지우개면 지름
4. 펜·도형이면 굵기

연달아 누르면 0.9초 안의 변경은 되돌리기 한 번으로 묶는다. 선택 바의 A−, A+는 누르고 있으면 0.35초 뒤부터 반복한다.

## 자동 도형 맞춤

1. 펜이 5px 넘게 움직일 때마다 0.55초 타이머를 다시 건다.
2. 타이머가 끝나면 `recognize(pts)`가 판정한다.
   - 시작점과 끝점이 가까워야 한다(닫힌 모양).
   - 가장 먼 점에서 고리를 둘로 나눠 Douglas–Peucker로 꼭짓점을 줄이고, 거의 직선인 꼭짓점을 지운다.
   - 꼭짓점 3개와 면적비 0.28~0.72 → 세모(꼭짓점 그대로)
   - 꼭짓점 4개와 면적비 0.74 초과 → 네모
   - 꼭짓점 4개 이상과 면적비 0.64~0.9 → 동그라미
3. 맞으면 획을 도형으로 바꾸고 "○○로 맞춤 · 원래대로" 칩을 3.5초 보여 준다.

## 선택, 회전, 크기

- `pickItem`: 위에서부터 찾는다. 획은 선까지 거리, 글·다이어그램은 상자 안, 나머지 도형은 테두리까지 거리로 판정한다.
- 도형·글 하나를 고르면 오른쪽 위에 회전 손잡이, 오른쪽 아래에 크기 손잡이를 그린다. 화살표는 회전만 된다.
- 회전은 0°, 90°, 180°, 270° 근처 4° 안에서 붙는다.
- 여러 개를 묶으면 이동, 복제, 삭제, 색 바꾸기만 된다.

## 지우개

- 지름은 `eraserSize`(기본 36px) 하나로 정한다. 원 커서, 화면에서 지워 보이는 폭, 실제로 잘라내는 범위가 모두 이 값이다.
- 펜을 대기만 해도(호버) 원이 따라온다. 손가락처럼 호버가 없으면 누르는 동안만 보인다.
- 그리는 동안은 `destination-out`으로 지워 보인다.
- 손을 떼면 `applyErase`가 획의 경로 근처 점을 잘라 조각으로 나눈다. 옮겨도 돌아오지 않는다.
- 도형은 테두리에, 글은 상자 안에 닿으면 통째로 지운다. 다이어그램 안쪽에 쓴 판서를 지우다 상자가 지워지지 않게 하려는 것이다.

## 되돌리기

- 바뀌기 직전 배열을 JSON 문자열로 쌓는다(최대 80개).
- 선택해서 옮길 때는 실제로 움직인 순간에만 쌓는다. 누르기만 해서는 쌓이지 않는다.
- 페이지를 바꾸면 기록을 비운다.

## 배경

- `<body data-bg>`가 `white` 또는 `chalk`. CSS 변수가 글자색, 강조색, 다이어그램 제목 칸 색을 함께 바꾼다.
- 팔레트는 같은 자리끼리 짝이다. 화이트의 검정 ↔ 칠판의 흰색처럼 모든 페이지와 되돌리기 기록의 색을 바꾼다.
- 글 서식 안의 색(글자색, 형광펜)도 hex와 rgb 표기 둘 다 찾아 짝 맞춰 바꾼다.
