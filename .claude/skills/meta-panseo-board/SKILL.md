# meta-panseo-board

펜·터치 기기에서 바로 여는 판서보드 HTML 한 장을 만든다.
본체는 슬라이드가 아니라 손으로 쓰고 그리는 칠판이다.

## 이 폴더

| 파일 | 하는 일 |
|---|---|
| SKILL.md | 이 문서 |
| template/board_template.html | 판서 엔진이 든 템플릿 |
| reference/tools.md | 엔진 내부 구조 설명 |

## 산출물

`<이름>_판서보드.html` 하나만 만든다.
외부 의존성 없이 브라우저에서 바로 열린다.

## 만드는 법

1. template/board_template.html을 `<이름>_판서보드.html`로 복사한다.
2. `{{DECK_TITLE}}`과 STEPS START부터 STEPS END 사이를 채운다.
   - 빈 판서보드: `<section class="step active"></section>` 하나만 남긴다. 화살표와 쪽 표시는 엔진이 알아서 숨긴다.
   - 배경 화면이 필요할 때: 컷을 6~9개로 나눈다. 컷마다 큰 메시지 한 줄과 보조 한 줄까지만 쓴다. 나머지는 판서로 채운다.
3. 시작 배경을 정하려면 `<body data-bg="navy">`를 `chalk`, `white`, `black` 중 하나로 바꾼다. 화이트보드를 원하면 `white`로 둔다.
4. 다른 파일은 만들지 않는다.

## 고치는 곳과 고치지 않는 곳

엔진의 `<style>`과 `<script>`는 고치지 않는다.
강의마다 바꾸는 곳은 아래뿐이다.

- STEPS 영역의 `.step` 섹션
- `<title>`
- `<body data-bg>` 시작 배경
- 필요하면 `:root`의 강조색 변수

## 엔진이 주는 도구

| 도구 | 키 | 하는 일 |
|---|---|---|
| 펜 | | 화면에 바로 판서한다. 색 5종, 굵기 3종 |
| 배경 | w | 남색, 칠판, 화이트보드, 검정을 고른다. 마지막 선택을 브라우저에 기억한다 |
| 판서모드 | b | 슬라이드를 가리고 빈 칠판으로 바꾼다 |
| 모눈 | g | 판서모드 칠판에 모눈 격자를 깐다 |
| ✂ 선택 | | 사각형으로 묶은 획들을 끌어 옮긴다 |
| ✋ 이동 | | 누른 곳에서 가장 가까운 한 획만 집어 옮긴다 |
| 지우개 | e | 지나간 부분의 점을 실제로 잘라낸다. 옮겨도 복원되지 않는다 |
| 되돌리기 | Ctrl+Z | 한 동작씩 되돌린다 |
| 전체지움 | c | 현재 화면의 판서를 모두 지운다 |
| 고정 | Esc | 떠 있는 선택 조각을 내려놓는다 |
| 슬라이드 | ←, → | 컷을 넘긴다 |
| ⛶ | | 좌상단 버튼으로 전체화면을 켜고 끈다 |

화이트보드를 고르면 펜 색이 진한 색 세트로 바뀐다.
이미 그린 획도 같은 자리의 색으로 함께 바뀐다.

## 검증

만든 뒤 문법을 먼저 확인한다.

```bash
node -e "const s=require('fs').readFileSync('<이름>_판서보드.html','utf8');new Function(s.match(/<script>([\s\S]*)<\/script>/)[1]);console.log('ok')"
```

브라우저에서 아래를 확인한다.

- 흰색과 노란색 획을 교차해 그린 뒤 ✋이동으로 하나만 잡히는지
- 획 중간을 지운 뒤 그 획을 옮겨도 지운 부분이 돌아오지 않는지
- 화이트보드로 바꿨을 때 기존 획이 보이는 색으로 바뀌는지
- 100% 화면에서 하단 툴바 라벨이 한 줄로 나오는지
- b, g, w, ⛶ 동작
