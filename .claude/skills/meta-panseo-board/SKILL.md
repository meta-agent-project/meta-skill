# meta-panseo-board

펜·터치 기기에서 바로 여는 판서보드 HTML 한 장을 만든다.
본체는 손으로 쓰고 그리는 보드이고, 슬라이드는 그 뒤에 깔리는 배경이다.

## 이 폴더

| 파일 | 하는 일 |
|---|---|
| SKILL.md | 이 문서 |
| template/board_template.html | 판서 엔진이 든 템플릿 |
| reference/tools.md | 엔진 내부 구조 |
| reference/motion.md | 모션 슬라이드 작성법 |

## 산출물

`<이름>_판서보드.html` 하나만 만든다.
외부 의존성은 IBM Plex Sans KR 웹 글꼴 하나다. 인터넷이 없으면 시스템 글꼴로 대신 보인다.

## 무엇을 만들지 정하기

| 요청 | 만드는 것 |
|---|---|
| 내용 요청이 없다 ("판서보드 만들어줘") | 흰 빈 페이지 한 장. STEPS에 `<section class="step"></section>` 하나만 둔다 |
| 칠판을 원한다 | 위와 같고 `<body data-bg="chalk">` |
| 주제나 내용을 준다 | 모션 슬라이드. 작성법은 reference/motion.md |

모션 슬라이드라도 판서 기능은 그대로다. 페이지마다 판서가 따로 저장된다.

## 만드는 법

1. template/board_template.html을 `<이름>_판서보드.html`로 복사한다.
2. `{{DECK_TITLE}}`을 채운다.
3. STEPS START부터 STEPS END 사이를 위 표대로 채운다.
4. 시작 배경은 `<body data-bg>`로 정한다. `white`(기본) 또는 `chalk`.
5. 다른 파일은 만들지 않는다.

## 고치는 곳과 고치지 않는 곳

엔진의 스타일과 스크립트는 고치지 않는다.
강의마다 바꾸는 곳은 아래뿐이다.

- `<title>`
- STEPS 영역의 `.step` 섹션
- `<body data-bg>`

## 화면 구성

왼쪽 레일 하나에 도구를 모은다. 오른손은 펜, 왼손은 레일을 쓴다.

| 자리 | 들어 있는 것 |
|---|---|
| 왼쪽 레일 | 펜, 지우개, 선택 · 도형, 텍스트 · 자주 쓰는 색 3개 · 되돌리기, 더보기 |
| 레일 오른쪽 펼침 | 펜을 한 번 더 누르면 색 5개, 굵기 3개, 도형 자동 맞춤 켜고 끄기 |
| 레일 오른쪽 펼침 | 도형을 누르면 5종 |
| 더보기 | 모눈, 빈 페이지 추가, 이 페이지 판서 지우기, 단축키 |
| 오른쪽 위 | 페이지 이동(2장 이상일 때만), 화이트·초록 배경, 전체화면 |
| 선택한 것 위 | 글 고치기, 복제, 삭제 |

## 도구

| 도구 | 키 | 하는 일 |
|---|---|---|
| 펜 | P | 판서. 세모·네모·동그라미를 그리고 펜을 떼지 않은 채 0.5초 멈추면 반듯한 도형으로 바뀐다. "원래대로"로 되돌릴 수 있다 |
| 지우개 | E | 획은 지나간 부분만 잘라낸다. 도형과 글은 테두리에 닿으면 통째로 지운다 |
| 선택 | V | 누르면 한 개를 잡는다. 겹친 획도 하나만 잡힌다. 빈 곳을 끌면 여러 개를 묶는다 |
| 도형 | 1~5 | 끌어서 그린다. 눌렀다 떼면 기본 크기로 놓는다 |
| 다이어그램 박스 | 5 | 제목 칸이 있는 네모. 만들자마자 글 입력이 열린다. 첫 줄은 제목, 다음 줄부터 내용 |
| 텍스트 | T | 누른 자리에 글 상자를 연다. Esc나 바깥을 누르면 닫힌다 |
| 회전 | | 도형·글을 선택하면 오른쪽 위에 회전 손잡이가 나온다. 0°, 90° 근처에서 붙는다 |
| 크기 | | 오른쪽 아래 네모 손잡이로 바꾼다 |
| 글 고치기 | | 글·다이어그램을 두 번 누르거나 선택 바의 T |
| 배경 | W | 화이트와 초록 칠판. 바꾸면 판서 색도 짝 맞춰 바뀐다 |
| 모눈 | G | 46px 격자 |
| 모션 다시 | R | 지금 페이지 모션을 처음부터 |
| 페이지 | ←, → | 2장 이상일 때 |
| 되돌리기 | Ctrl+Z | 한 동작씩 |
| 삭제 | Del | 선택한 것 삭제 |

## 검증

문법을 먼저 확인한다.

```bash
node -e "const s=require('fs').readFileSync('<이름>_판서보드.html','utf8');new Function(s.match(/<script id="engine">([\s\S]*?)<\/script>/)[1]);console.log('ok')"
```

브라우저에서 아래를 확인한다.

- 대충 그린 네모, 동그라미, 세모가 멈추면 맞춰지는지
- 다이어그램 박스를 회전 손잡이로 돌릴 수 있는지
- 텍스트 박스를 놓자마자 첫 글자부터 입력되는지
- 획 중간을 지우고 그 획을 옮겨도 지운 부분이 돌아오지 않는지
- 초록 배경으로 바꾸면 기존 판서가 보이는 색으로 바뀌는지
- 모션 슬라이드가 페이지에 들어올 때 재생되는지
